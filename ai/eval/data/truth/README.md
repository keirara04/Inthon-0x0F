# 정답 파일 (truth) — ⚠️ 검수 전 초안

`<층>.json`은 평가 기준이자 백엔드 `verified` 백업 데이터 후보입니다. 형식은 팀 그래프 JSON과 같습니다.

## 만든 방법 (2026-10-31, 상후 + AI)
1. 각 층 정면 사진(`evac/evac_<층>_front.jpg`)으로 Gemini 3.8 Flash가 만든 결과 중 가장 좋은 것을 초안으로 사용
2. 사진과 대조해 확인: 호실 번호, 계단 2개, 엘리베이터(승강로 기호), 현위치, 1F 주출입구
3. 수정: 4F 북쪽 복도 y좌표를 대피로 선 위치로 이동, id·라벨 통일
4. `heading_deg`: 노드 좌표에서 계산 (안내도 위쪽 = 북쪽 가정, **실제 방위 보정 안 됨**)
5. `length_m`: 노드 좌표 거리 × 층별 축척 (축척은 모델 추정치의 중앙값, **실측 아님**)

좌표는 각 층 **정면 사진** 기준입니다.

## 명성 검수 체크리스트
- [ ] 호실 목록이 실제와 같은가 (1F 9개, 2F 10개, 4F 16개)
- [ ] 1F 106A·107A가 무슨 방인가 (화장실 부속? 창고?) → label 수정
- [ ] 1F 번호 없는 왼쪽 큰 공간(로비/열람실?) → 필요하면 노드 추가
- [ ] 1F 서측 계단 아래 녹색 비상구가 건물 밖으로 나가는 문인가 → 맞으면 exit 노드 추가
- [ ] 각 방 문이 실제로 연결된 복도 위치 (방에서 복도로 가는 간선이 맞는가)
- [ ] 층마다 안내도 위쪽이 실제 몇 도인지 (나침반) → 백엔드 방위 보정값
- [ ] 엘리베이터 정차 층 (엘리베이터 안 버튼) → `elevators` 채우기
- [ ] 검수가 끝나면 이 README의 제목에서 "초안"을 지우고 날짜·검수자 기록

검수 전에 이 파일로 낸 지표는 "AI 초안 + 사진 대조 기준"이라고 명시해야 합니다.
