# 체크포인트 사진 촬영 목록 (우정정보관)

체크포인트 인식(문패·층 표지 읽기) 정확도와 속도를 재는 데 쓰는 사진입니다. **마감: 10/31(토) 24:00**

- 채점은 시드 데이터가 있는 **1F·4F만** 됩니다. 1F·4F를 먼저 찍어 주세요.
- 우선순위: **① 4층 문패 → ② 층 표지 → ③ 표지 없음 → ④ 1층 문패**
- 다 찍으면 `ai/eval/data/checkpoint/`에 넣어 주세요 (사진은 git에 올라가지 않습니다).

## 파일 이름 규칙

`<종류>_<번호 또는 층>_<조건>.jpg`

| 조건 | 뜻 |
|---|---|
| `near` | 1m 이내, 정면 |
| `far` | 3~5m 떨어져서 |
| `angle` | 비스듬히 (약 45°) |
| `dark` | 어둡거나 역광 |
| `blur` | 걸으면서 찍어 조금 흔들림 |

같은 조건을 두 번 찍으면 끝에 번호를 붙입니다: `room_405_near_2.jpg`
